### 🔑 Principles of Asynchronous Writing

1. **Be Clear & Complete**
    - Write so the recipient has all the context without needing to ask follow-ups right away.
    - Example: Instead of _“What do you think?”_, write _“Here are 3 options for the project logo (attached). I recommend Option B because it’s simpler. What are your thoughts by Friday?”_.
2. **Set Expectations on Response Time**
    - Tell people when you need a reply (if at all).
    - Example: _“No action needed, just keeping you in the loop”_ vs. _“Please confirm by Wednesday”_.
3. **Use Structure & Formatting**
    - Use bullets, headers, or bold text so your message is scannable.
    - Async writing should be easy to read quickly.
4. **Choose the Right Channel**
    - Email → formal, longer updates.
    - Docs (Notion, Confluence, Google Docs) → detailed info or decisions.
    - Project tools (Jira, Trello, Asana) → task-based communication.
    - Chat (Slack, Teams) → short async updates, not urgent.
5. **Respect “Deep Work”**
    - Don’t expect instant replies. Async works because people can answer when they have the mental space.
---
### 🛠 Techniques for Effective Async Communication

- **Use “FYI” and “Action Needed” tags** at the top.
- **Summarize first, details later** (inverted pyramid style).
- **Write with permanence in mind** → your note should be understandable even if read days later.
- **Close with clarity** → end with what’s expected (reply? read only? deadline?).

## 📝 Async Communication Template

**Subject / Header:**  
`[Update] / [Request] / [FYI] – Short Description`
---
**Greeting:**  
Hi [Name/Team],

**1. Purpose (Why you’re writing)**

> One or two sentences that explain _why they’re receiving this message_.

**2. Key Points / Summary (Top-level info first)**

- [Bullet 1]
    
- [Bullet 2]
    
- [Bullet 3]
    

**3. Details (Optional, if they need more context)**  
Provide background, reasoning, or attachments/links here. Keep this section scannable.

**4. Action / Next Steps**  
👉 [Action needed or confirmation request]

- Who: [Person/team responsible]
    
- What: [Task / decision]
    
- When: [Deadline or expected timeframe]
    

**5. Closing / Expectations**

- If no action: _“This is for visibility only, no reply needed.”_
    
- If action: _“Please reply by [date].”_
    

Best regards,  
[Your Name]
